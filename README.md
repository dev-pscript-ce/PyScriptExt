English:
Pscript is a compact interpreted language that includes a command-line runtime environment for Windows x64, along with an extension for Visual Studio Code.
This is a trial version of PScript (PyScriptExt); due to the absence of the `pscript.exe` and `pscript-analyzer.exe` files, it will only function correctly when tested within the VS Code Extension Development Host (EDH) environment.

Vietnamese:
Pscript là một ngôn ngữ thông dịch nhỏ gọn, đi kèm với môi trường thực thi dòng lệnh trên Windows x64 và một tiện ích mở rộng (extension) dành cho Visual Studio Code.
Đây là phiên bản dùng thử của PScript (PyScriptExt); do thiếu các tệp `pscript.exe` và `pscript-analyzer.exe`, phiên bản này sẽ chỉ hoạt động đúng cách khi được kiểm thử trong môi trường phát triển tiện ích mở rộng của VS Code (Extension Development Host - EDH).
